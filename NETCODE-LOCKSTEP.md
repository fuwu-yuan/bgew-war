# Lockstep / input-based netcode (branch `feat/lockstep`)

Goal: the guest runs its OWN game loop instead of rendering a per-tick stream
from the host. Over the wire we send only the **seed** + **player commands**
(build/upgrade/strike/helico/axis) + a periodic **correction**. The guest's
unit motion no longer depends on receiving network data every frame, so jitter
spikes can't freeze it.

## Why a correction channel (not pure lockstep)
The sim randomness is pervasive (unit speed/lane/fire/convert timing, building
spawn timing+position) and the movement uses floating-point + `Math.sin/exp`,
which are **not** bit-identical across machines/browsers. Pure lockstep would
desync over time. So we run a best-effort deterministic sim and have the host
send a **full-state correction ~1×/s** (reusing the existing snapshot) that the
guest snaps/eases onto. Imperfect determinism self-heals every second; bandwidth
stays tiny (1 snapshot/s vs ~12/s today).

## Determinism requirements
1. **Seeded PRNG** — every SIM random draw uses one shared `makeRng(seed)`
   (mulberry32, integer-only). Seed sent host→guest in `init`. Cosmetic random
   (particles, walk anim, sounds, menus) stays on `Math.random` — it doesn't
   touch sim state. (AI random is solo-only → irrelevant to MP.)
2. **Fixed timestep** — the sim advances in fixed steps (e.g. 1/30 s) via an
   accumulator, decoupled from the render frame rate; render interpolates.
3. **Identical iteration order** — units/buildings processed in the same order
   both sides (insertion-ordered arrays/maps; deterministic sweep).
4. **Map** — generated by the host, sent once in `init` (already the case), so
   it needs no seeding.

## Phases (each verified headless: 2 sims, same seed+inputs, compare a state hash)
- [x] **0. Foundation** — `makeRng` PRNG + share `seed` in `init`. (non-breaking)
- [ ] **1. Fixed timestep** — accumulator loop; render interpolation; sim no
      longer reads wall-clock `delta`.
- [ ] **2. Seed the sim** — route ALL sim random (units/buildings/game.step
      spawns+combat timing) through the match RNG, in a fixed draw order.
- [ ] **3. Commands at a tick** — both sides buffer commands by target tick and
      apply them at the same tick (small input delay).
- [ ] **4. Guest runs the sim** — drop the `role !== "guest"` gates; the guest
      simulates locally instead of mirroring.
- [ ] **5. Correction** — host sends a full snapshot ~1×/s; the guest reconciles
      (snap buildings, ease unit positions). Detect drift via a cheap checksum.

## Rollback
All of this lives on `feat/lockstep`. `main` keeps the working host-authoritative
snapshot model (v1.6.0, deployed). Merge only once the headless determinism +
correction tests are green.
